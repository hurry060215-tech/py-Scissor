# Independent differential review

These additional fixtures were generated by a separate review pass using the
unmodified pinned Scissor R sources and actual compiled C++ implementation.
They are distinct from the primary 22-file fixture suite.

- `random_paths.json`: 8 R seeds × p=1/6 × 3 families × alpha=0/0.4/1,
  four explicit lambdas. 144 attempts: 120 defined finite paths and 24
  p=1 Cox wrapper errors (`incorrect number of dimensions`).
- `unequal_fold_cv.json`: 10 R seeds × 3 families × alpha=0.4/1,
  four explicit lambdas and deliberately unequal fold sizes. All 60 succeed.

The graphs are safe irregular graphs with the final two nodes isolated. This
does not establish compatibility for unsafe or arbitrary graph configurations.

The generators are preserved in the [separate fixed development archive](https://github.com/hurry060215-tech/py-Scissor/tree/2cb65ba5af3e1ffac05226f66d0e0ddf1eb7dc50/reference/review). In that archive checkout only, reproduce with R/Rcpp/RcppEigen/Matrix/jsonlite installed:

```sh
Rscript reference/review/generate_random_paths.R "$PWD/reference"
Rscript reference/review/generate_unequal_fold_cv.R "$PWD/reference"
```

The Python regression test checks these stored results without R.
Defined coefficients, CV mean loss, CV standard error, and selected lambda
matched within absolute 1e-7 in the independent review. Wrapper failures are
also tested as explicit official-mode rejection boundaries.

Review also found a Python stale-convergence flag after active-set restart.
That issue was fixed before delivery and both Gaussian/binomial reproducers
are now regression tests. Corrected binomial was changed to exact-logistic
objective/KKT after review of the initial clipped-score implementation.
The review also found random_state=None/Generator regenerated folds at each
alpha. Folds are now created once and regression-tested for both RNG forms.
